# MedEvidence-AI V2 — Clinical Claim Extraction

V2 introduces the first interactive component of MedEvidence-AI.

## Workflow

AI-generated response  
→ Claim extraction  
→ Claim classification  
→ Verification queue

## Objective

Identify the clinical statements contained in an AI-generated medical response that require independent evidence verification.

## Claim categories

- Medical fact
- Diagnostic claim
- Recommendation
- Clinical statement

## Important principle

V2 does not decide whether a claim is true or false.

It identifies claims that should be independently verified.

## Status

Experimental prototype.
