# MedEvidence-AI V1 — Concept

Première version du projet MedEvidence-AI.

Cette version définit le concept d'un workflow "verification-first" pour la recherche clinique assistée par IA.

## Workflow

Clinical Case  
→ Case Structuring  
→ Clinical Question  
→ Evidence Search  
→ AI-Assisted Synthesis  
→ Claim Extraction  
→ Source Verification  
→ Correction  
→ Final Evidence-Backed Response

## Objectif

Réduire le risque d'utiliser comme preuves des informations médicales générées par une IA sans vérification indépendante.

## Statut

Prototype conceptuel — version initiale.
