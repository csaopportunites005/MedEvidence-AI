# MedEvidence-AI V5 — Evidence-backed Synthesis

V5 brings together the main components of the MedEvidence-AI verification-first workflow.

## Workflow

AI-generated response  
→ Claim extraction  
→ Claim classification  
→ Evidence sources  
→ Claim-source verification  
→ Correction  
→ Evidence-backed final response

## Objective

Produce a final clinical research response in which important medical claims are linked to verified evidence and clearly distinguished from interpretation or uncertainty.

## Final output

The system should distinguish between:

- Evidence-supported claims
- Partially supported claims
- Unsupported claims
- Unverified sources
- Clinical interpretation
- Remaining uncertainty

## Important principle

MedEvidence-AI does not treat an AI-generated answer or citation as automatically reliable.

Claims should be extracted, checked against relevant evidence, and corrected when necessary.

## Responsible use

This project is an experimental research and educational prototype.

It is not a medical device, does not provide autonomous clinical decisions, and does not replace qualified clinical judgment.
